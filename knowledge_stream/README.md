# Gvault Knowledge Stream

Flux public de productions issues du moteur récréatif Gvault.

Statut : **PUBLIC KNOWLEDGE OUTPUT**.

Ce flux publie les artefacts de savoir produits par les blobs non électriques : expériences, prototypes, mini-jeux, galeries et croisements. Les captures de conversation, ledgers privés, secrets, données d'identité ou état interne du Gvault ne sont pas exportés ici.

- `batches/FIRST_LIVE_BATCH_001.json` — 16 artefacts produits.
- `batches/LIVE_BATCH_002.json` — 24 artefacts produits.
- **Total actuel : 40 artefacts de savoir.**

## Jeux matérialisés

- `games/atelier_des_elements.html` — atelier jouable FEU / AIR / TERRE.

## Politique de diffusion

- diffusion publique des sorties de savoir : OUI ;
- provenance conservée : OUI ;
- promotion automatique en vérité canonique : NON ;
- électrique : EXCLU du flux automatique ;
- données privées/captures/ledger : NON EXPORTÉES ;
- les lots sont des snapshots, pas des quotas de population.

## Principe

`blob admis par le scheduler → production concrète → artefact traçable → export public de savoir`

Les résultats expérimentaux restent des résultats expérimentaux jusqu'à validation séparée.

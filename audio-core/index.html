Les extensions à brancher sans se vendre

OPTION LOCALE / GPU

ACE-Step 1.5

Génération chantée en plusieurs langues, reprises, retouches, extraction de pistes. Licence MIT annoncée. Pas installé : nécessite un environnement et un serveur local ou une application.

OPTION PC

Audio Separator

Vraie séparation de pistes : voix, instruments, batterie. Aucun moteur de séparation n'est intégré dans cette page.

OPTION WEBGPU

Transformers.js

Pour reconnaissance ou synthèse vocale locale avec un modèle compatible, à installer ultérieurement. WebGPU dépend du matériel et du navigateur.

FONDATION WEB

Tone.js

Framework de séquençage et d'effets. Notre station fonctionne en Web Audio natif, sans chargement externe.

RECHERCHE / LICENCE

AudioCraft / MusicGen

Code MIT, mais poids MusicGen non commerciaux CC BY-NC 4.0. Licence à vérifier avant toute exploitation commerciale.

Pas de trompe-l'œil

ACTIF Synthèse locale, deux platines, mix, radio privée, enregistrement, import, WAV/MIDI via 2078.

NON BRANCHÉ Gros modèles d'IA, séparation de stems neuronale, chant intelligible neural, diffusion publique multiutilisateur.

À INVENTER Coopération entre moteurs, expression vocale émergente, composition multi-temps, radio interactive, apprentissage consentant.

Le deep web n'est pas un catalogue de modèles fiable. Cette station ne fouille pas des services cachés et ne télécharge rien à ton insu.

# TUBE · Édition sobre GVAULT AUDIO CORE

Version autonome : [ouvrir le fichier HTML](tube.html).

## Démarrage
Ouvrir `audio-core/tube.html` dans Chrome, Opera ou un navigateur récent.
Saisir une idée musicale, choisir couleur/énergie/format, cliquer « Générer un morceau », écouter et télécharger.

## Fonctionnalités effectives
- Génération algorithmique de morceaux structurés avec refrain thématique répété, batterie, basse, harmonie, arpèges, mélodie et vocalises synthétiques facultatives.
- Modes Auto / Soul / Rap / Pop / Électro / Rock / Ambient.
- Arrangements intro, couplets, refrains, pont et fin.
- Lecture, pause, recherche temporelle, forme d'onde, variantes, conservation du motif de refrain.
- WAV stéréo PCM 16 bits 24 kHz, MIDI des notes, projet JSON incluant les paroles de référence.
- Favoris locaux, avec repli session si le navigateur bloque le stockage.

## Limites explicites
Ce moteur ne chante pas encore les paroles intelligiblement. Il ne comprend pas le texte comme un LLM et ne peut pas remplacer Suno pour la génération vocale réaliste. Les durées varient suivant le BPM. Aucun compte, modèle externe, serveur ou paiement n'est requis.

## Intégration
`tube.html` est un module indépendant à côté de `index.html`, `studio2078.html`, `voice-lab.html`, `fabrique-v1.html`. Aucune réécriture des autres cœurs.
